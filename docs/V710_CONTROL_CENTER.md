# V710 Broadcast Control Center

Indeholder:
- System status: Website, GitHub, Worker, Twitch, OBS, StreamElements, RSS.
- Broadcast metrics: followers, subs, bits, requests.
- Countdown til næste show.
- Automatisk næste program baseret på programplan.
- Admin-redigering af systemstatus.
- V700.2 admin repair og 3 sprog er bevaret.

Bemærk:
Twitch/OBS/StreamElements/RSS er stadig placeholders i V710. De bliver rigtige integrationer i V720+.
